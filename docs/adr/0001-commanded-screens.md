# Commanded Screens over a TUI or a one-shot card

This is a portfolio CLI, not a live TUI and not only a Dev Card. Default invocation prints the Dev Card; a Screen name (and optional Role/Project slug) selects what to print. `@comark/ansi` renders markdown to stdout, so interaction is argv, not a full-screen app.

**Considered Options**: one-shot Dev Card; commanded Screens; live TUI (Ink/OpenTUI).
