# Ship via npx, bunx, and compiled binaries

A stranger should run this with `npx sethyrung`, `bunx sethyrung`, or a curl-installed binary from GitHub Releases. Binaries cover Linux, macOS, and Windows (x64 and arm64). Dev/test stay on Bun; the published JS entry must also run on Node so npx works.

**Considered Options**: npx-only; bunx-only; compiled binary only; all three.
